Login

  1. Open the login page and enter your authorized account credentials.
  2. After successful login, open Admin Dashboard.
  3. Use the left sidebar to expand a management group.
  4. Use View website ↗ to verify public changes.
  5. Use the sign-out icon when finishing your session.
Security: Use a unique password, do not save credentials on a shared device, and always sign out after administrative work.

Standard record controls

  • Create/Add: opens a blank management form.
  • Edit: opens an existing record and preserves uploaded files unless replaced or cleared.
  • Delete: removes a record; confirm the correct record before proceeding.
  • Active: controls operational availability.
  • Publishing: controls whether public content is draft, published or archived.
  • Display order: lower numbers normally appear first.
Menus are permission-aware. If a section is missing, ask a Super Admin to review the account’s role and permissions.

Creating a Project — Correct Sequence

Locations & type→Create project→Add media→Add units/progress→Publish & verify

1. Prepare related records

Before creating a project, confirm its Property Type, Division, District, Area, and Amenities exist. Create missing values under Property Management.

2. Create the project

  1. Go to Property Management → Projects and choose Add/Create.
  2. Enter Name, unique Slug, unique Code, short description and full description.
  3. Select property type, project status and DRAFT publishing status.
  4. Select Division, District and Area in that order; then choose amenities.
  5. Enter address, Google Maps URL and coordinates if available.
  6. Enter land/building data, apartment counts, size range, price range and currency.
  7. Set construction and handover dates.
  8. Upload Featured Image, Hero Banner, Features Image and Enquiry Image as required.
  9. Upload the Brochure PDF, add video/tour URLs, display order and SEO fields.
  10. Enable Active, save, then reopen the record and confirm all values.
Important: The project must be saved before gallery images, apartment types, units or construction updates can be attached to it.

Gallery Images & Floor Plans

Add an image to a saved project

  1. Go to Property Management → Media gallery.
  2. Choose Add/Create and select the saved project.
  3. Select the media Type.
  4. Upload an image, or supply an external URL when appropriate.
  5. Add a useful Caption and Alternative Text.
  6. Set Display Order and save.
  7. Repeat for each image and verify the project details page.
TypeUse
EXTERIORBuilding façade, entrance and outside views.
INTERIORLiving, bedroom, kitchen and common interior spaces.
CONSTRUCTIONSite and construction-stage photographs.
ARCHITECTURALRenderings, elevations and architectural details.
FLOOR_PLANApartment and floor plan images; shown in the project gallery/plans area.
VIDEOVideo-related record using a suitable URL/thumbnail workflow.
VIRTUAL_TOURInteractive or external virtual-tour destination.
Recommended: Use consistent landscape dimensions, optimized file sizes, descriptive alt text, and orders such as 10, 20, 30 so images can be inserted later.

Brochure & Price-Enquiry Workflow

Upload or replace a brochure

  1. Go to Property Management → Projects.
  2. Edit the required project.
  3. Find Brochure PDF, choose the PDF, and save.
  4. Open the public project page and choose Download Brochure.
  5. Submit the lead form, verify the confirmation, PDF viewer, new-tab viewer and download.

The public project actions appear in this order:

Book a Consultation→Download Brochure→Unlock Price
  • Brochure requests are saved as enquiries.
  • If no PDF is uploaded, the lead is still recorded and the visitor is told a consultant will provide it.
  • Unlock Price records a price request and offers a project-specific WhatsApp continuation.
  • The WhatsApp destination uses the number/link configured under Site Settings.
Upload PDF files only. After replacement, hard-refresh the public page if the previous document remains cached.

Apartments, Units & Construction

Apartment types

  1. Open Property Management → Apartment types.
  2. Select the parent project.
  3. Enter the apartment configuration, size and supporting floor-plan information.
  4. Save and verify it appears in the project overview.

Units & inventory

  1. Open Units & inventory and select the correct project and apartment type.
  2. Enter unit/floor identifiers and availability information.
  3. Update inventory promptly when reservation or sales status changes.

Construction progress

  1. Open Construction progress and select the project.
  2. Add the progress date, completion percentage, title and description.
  3. Save; the latest progress percentage is used on the project page.
Keep completion percentages factual and approved. The newest progress record should represent the current public status.

Suggested enquiry lifecycle

NEW→CONTACTED→QUALIFIED→NEGOTIATION→CONVERTED / LOST
  • Do not delete valid leads merely because they are completed.
  • Keep internal notes professional and factual.
  • Avoid storing unnecessary sensitive information.
  • Assign follow-up dates and update status after every meaningful interaction.

Careers, Settings & Users

Careers

  • Create and publish Job Openings with accurate requirements, location and deadline.
  • Review Applications from the Applications section.
  • CV files contain personal information—download and share only with authorized staff.

Site settings

  • Company name, logo and favicon.
  • Hotline, email, office address and business hours.
  • Footer content and public navigation labels.
  • Social links, including the full WhatsApp link such as https://wa.me/8801....
  • Default SEO title and description.
  • Contact-page images and field labels where available.

Users, roles and permissions

  • Create individual accounts; never share a single administrator account.
  • Grant only the permissions required for the person’s work.
  • Remove or disable access immediately when responsibilities change.
  • Reserve Super Admin access for trusted system administrators.

Publishing & Quality Checklist

  • Project name, slug and code are correct.
  • Status and publishing state are correct.
  • Location hierarchy is correct.
  • Address and map open correctly.
  • Building and apartment figures are accurate.
  • Price values and currency are approved.
  • Dates are accurate.
  • Featured and hero images load.
  • Gallery order is correct.
  • Floor plans open clearly.
  • Brochure opens and downloads.
  • Consultation form submits.
  • Unlock Price opens WhatsApp.
  • Mobile layout has been checked.
  • SEO text is complete.
  • Spelling and punctuation are reviewed.
